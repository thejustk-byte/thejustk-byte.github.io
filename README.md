# Thejus T.K. interactive portfolio

A single-screen, responsive portfolio for GitHub Pages. The portrait and topic cards stay on one canvas; selecting a card opens an animated information bubble. The site uses static HTML, CSS and JavaScript and needs no build step.

## Publish with GitHub Pages

1. Open the repository `thejustk-byte/thejustk-byte.github.io` on GitHub.
2. Replace the site files in the repository root with the files from this folder. Keep `index.html`, `quick-catch-up.html`, `card.html`, `assets/`, `portrait.jpg`, `resume.pdf` and `contact.vcf` together at the root.
3. Commit the changes to `main` and push them to GitHub.
4. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save if Pages is not already configured.
5. Wait for Pages to finish deploying, then open `https://thejustk-byte.github.io/`.

The site is published at `https://thejustk-byte.github.io/`. `assets/site.css` and `assets/site.js` contain the layout, animated topic bubbles, keyboard behavior and reduced-motion support. The supplied portrait, résumé PDF and contact card are included as-is.
